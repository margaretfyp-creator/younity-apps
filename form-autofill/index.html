Form Auto-Fill

Load the blank form, set where each detail goes, add customers, then export the filled PDFs. Everything runs in this browser and nothing is uploaded.

No form loaded
This PDF has built-in fillable fields. Pick which customer detail goes into each one. You can also place text anywhere in step 3.
Share or restore the setup
The setup file has the blank form and field positions but no customer data, so teammates can use the same layout.

2 Customers

Recognised columns are Name, IC / NRIC and Policy No. Any other column (e.g. Agent Code, Phone) is also kept and can be placed on the form.

3 Field positions

Click Place on form, then click the start of the blank on the preview. You can drag markers to adjust them, or select one and use the arrow keys (hold Shift for bigger steps). For boxed fields such as IC, set Box to the width of one box so each character lands in its own box.
