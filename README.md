# Younity Apps

Installable web apps, hosted on GitHub Pages.

- **Panel Clinic Finder** (`panel-clinic/`): nearest Great Eastern panel clinics and hospitals by postcode, street or area, with services, doctors, opening hours and Google Maps / Waze directions, in English and Mandarin. Add `#agent` to the address for the advisor view (medical-exam clinics, WhatsApp / email messages, PDF).
- **Form Auto-Fill** (`form-autofill/`): load a blank PDF form, place fields once, bulk-upload customers from Excel/CSV, export filled PDFs. Everything stays in the browser.

Panel lists are taken from Great Eastern Life Malaysia's public website (clinics 24 Oct 2026, hospitals 15 Sep 2026, specialists 2 Oct 2026, exam clinics 1 Oct 2026). Postcode positions: GeoNames (CC BY 4.0). This site is shared by Margaret Foo, Younity Consultancy, and is not run by Great Eastern.
